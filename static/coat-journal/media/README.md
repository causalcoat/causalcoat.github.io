# COAT introduction media

This directory contains publication derivatives only: English and Chinese one-minute films, ten-second silent loops (GIF and MP4), posters, WebVTT captions and transcripts. Full videos use click-to-play controls and do not autoplay. README images link here; media is not distributed in the Python package.

## Sources and attribution

- Script, layout and preset apple-review teaching example: COAT project.
- Research plots and case studies: Liu et al., JMLR 27(229):1–95, 2026, https://www.jmlr.org/papers/v27/25-2137.html . The financial plot is reproduced from the paper, not generated.
- Context illustrations: AI-generated using the DSH image tool, returned model `openai-compat/gpt-image-2.5`. Illustrations are not observations, measurement evidence or geographic data.
- Narration: DeepSeek TTS, Stella. Each language is synthesized as one continuous narration. No speed adjustment. English synthesis omitted the draft sentence “Descriptions become numbers”; captions and transcript reflect the spoken audio.
- Music: **A Small Discovery**, supplied by the project owner, generated with Suno. Embedded metadata: created 2026-11-16T08:08:08Z, id `3d79cde5-3ece-49eb-b619-47b1244c06e0`. The first minute is mixed quietly with speech-driven ducking and a fade-out. The original WAV is not included.

Software Apache-2.0 and example-data CC BY 4.0 licenses do not automatically apply to these composite media assets. No separate music redistribution license is granted here. Confirm the owner's Suno plan and applicable publication rights before public deployment. Paper figure rights remain with their respective holders.

Captions use phrase-level timings informed by short-window speech recognition; they are not word-level alignments. Static posters and readable transcripts remain available without animation or audio.

## Publication order

Deploy these website assets before publishing the software README links, to avoid temporarily broken images. The website is built from `content.py` and `build.py`; do not edit generated homepages independently. No external video player, analytics or API calls are required during playback.
